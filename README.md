# Geospatial Modelling of Flood Susceptibility and Population Exposure in the Ona River Basin

A GIS-based research project investigating flood susceptibility and population exposure within the **Ona River Basin, Southwestern Nigeria**.

## Project Overview

This project aims to identify areas within the Ona River Basin that are potentially susceptible to flooding and assess the population located within those susceptible areas.

The study combines GIS, remote sensing, environmental datasets, and spatial analysis to produce a flood susceptibility map and population exposure assessment.

## Research Question

Which settlements and populated areas within the Ona River Basin in Southwestern Nigeria are most susceptible to flooding, and how many people are potentially exposed to these flood-susceptible areas?

## Study Area

Ona River Basin, Southwestern Nigeria

## Key Data

The project will primarily use:

 Digital Elevation Model (DEM)
 River and stream network
Rainfall data
Land Use/Land Cover (LULC)
Soil data
Population data
Historical flood data

## Expected Outputs

Ona River Basin boundary
Flood susceptibility map
Settlement exposure map
Population exposure map
Final research-ready GIS maps
